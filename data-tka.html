Hubungkan data TKA.

Tempel URL Google Apps Script yang menghasilkan JSON. Halaman ini menyusun data mentahnya menjadi tabel dan kartu yang mudah dibaca — tanpa mengubah halaman lain di situs.

URL disimpan hanya di browser ini. Alamat sumber tidak ditulis ke repo dan tidak dikirim ke GitHub. Data diambil langsung dari Google.
Butuh bantuan?
  1. Buka URL data yang Anda miliki (yang berakhiran &lib=...).
  2. Salin seluruh alamat dari address bar.
  3. Tempel di kolom di atas, lalu klik Hubungkan.

Untuk sekali klik, buka halaman ini dengan #src=URL-terenkode. URL akan disimpan lokal, lalu hash dibersihkan dari address bar.

Direktori

Sekolah

Seluruh entri direktori sekolah. NIP kepala sekolah dan kata sandi disamarkan saat mode aman aktif. Klik judul kolom untuk mengurutkan.

Pendaftaran

Peserta

Nama sekolah diambil dari relasi school_id karena kolom school_name pada data mentah kosong. NISN, NIS, NIK, nomor peserta, dan kata sandi disamarkan.

Pelaksana

Proktor

Nama proktor dan teknisi ditampilkan sebagai data mentah. Kata sandi dan alamat IP server disamarkan saat mode aman aktif.

Penilaian

Hasil TKA

Ringkasan nilai dan tabel hasil. Nama, NISN, dan nomor peserta disamarkan saat mode aman aktif. Perhatikan catatan tentang kolom Sekolah di bagian Sumber & catatan.

Butir soal

Bank soal

Seluruh butir dari data mentah, lengkap dengan stimulus, pilihan, dan kunci. Gunakan pencarian atau filter untuk menemukan soal tertentu.

Yang disamarkan

Mode aman
  • Identitas: NISN, NIS, NIK, dan nomor peserta.
  • Kredensial: kata sandi sekolah, peserta, dan proktor.
  • Akses: token ujian dan alamat IP server.
  • Kepegawaian: NIP kepala sekolah.

Matikan mode aman hanya saat layar Anda privat. Data tetap diambil langsung dari Google; halaman ini tidak menyimpan salinan di server.
